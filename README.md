> これは、AIを活用してアイデアを形にできることを実践で示すために作成した、あくまでサンプルです。
> This is only a sample, built to show in practice that AI can turn an idea into a working app.

訪日旅行者向け「リアル日本語×日本文化」学習アプリの試作品です。このリポジトリには公開用のビルド済みファイルだけを置いています。

- 公開URL: https://jj221192.github.io/real-japan-app/
- デザイン切替: `?design=neon`（夜の街）／`?design=manga`（マンガ・ポップ）
- 教材・イラストはすべて自作のサンプルです。実在の人物・店舗・写真は含みません。
- 決済はデモ表示のみで、支払いは発生しません。
